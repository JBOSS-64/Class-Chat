## Project Goal
The goal of this project is to create an app for students that will let them connect with their peers and never forget their assignments. I want this app to allow for the creation of collaborative communities of students where everyone can help everyone pass the class.

## Features
These are the features that I have completed or am currently working on implementing:
- [x] Classes
- [x] Class Group Chat
- [x] Assignments + Due dates
- [ ] Personalized homework/study planning
- [ ] Reminders for assignments and tests

After I finish these core features I plan to polish the app, and take a lot of user feedback on what to improve/add next.

## Creation
### Database
This app was built using [Supabase](https://github.com/supabase/supabase)

### AI Usage
This app was NOT created by generative AI. All of the code was written by me.

Google Gemini was simply used to assist me in understanding how to use some features of Supabase, as well as things I was unfamiliar with in JavaScript. It also assisted me in debugging.

Gemini did write a good bit of the CSS, but I will change this in the future, I simply used it so that I could quickly get the UI set up. I will re-write how the app looks once I am finished with the core features
